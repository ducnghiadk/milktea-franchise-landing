# Landing Page Nhượng Quyền Trà Sữa - Nghĩa

Landing page cho mô hình nhượng quyền trà sữa thực chiến 20+ điểm bán.

## Tech Stack
- HTML + Tailwind CSS (CDN)
- Google Fonts (Noto Serif + Manrope)
- Material Symbols Icons

## Deploy
Deployed on Vercel: Static HTML, no build step required.

## Sections
- Hero: Giới thiệu Nghĩa và mô hình
- Pain Points: 6 vấn đề thường gặp
- Solution: Giải pháp mô hình thực chiến
- Why Choose: 3 điểm khác biệt
- Benefits: Quyền lợi đối tác (Bento Grid)
- Process: 5 bước nhượng quyền
- Testimonials: Feedback đối tác
- FAQ: Câu hỏi thường gặp
- Contact Form: Form đăng ký tư vấn
